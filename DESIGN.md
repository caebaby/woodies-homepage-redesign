# Design System

## Direction

A modern neighborhood garage: cool service-bay white, Woodie's committed red, deep mechanic blue, documentary service imagery, and crisp signage-like typography. The page is designed for a worried driver using a phone in daylight.

## Color

- Paper: `oklch(0.97 0.006 250)`
- Cool surface: `oklch(0.93 0.012 250)`
- Ink: `oklch(0.22 0.025 255)`
- Muted ink: `oklch(0.45 0.025 255)`
- Woodie's red: `oklch(0.5 0.2 28)`
- Mechanic blue: `oklch(0.34 0.085 260)`
- Gold proof accent: `oklch(0.78 0.14 77)`

## Typography

Use a fast system stack. Headings are compact, heavy, and left aligned. Body copy stays below 70 characters per line. Small uppercase text is reserved for one proof label and navigation utility text.

## Layout

Use a strict 12-column desktop grid with deliberate asymmetry. The hero pairs conversion copy with one service image. Service choices use one large panel and two smaller stacked panels, not a repeated card grid. Mobile reduces to one clear column with a compact sticky action bar.

## Components

- Compact sticky header
- Primary red CTA and secondary outlined CTA
- Proof strip directly below conversion actions
- Location selector with a single concrete shop result
- Asymmetric service chooser
- Warranty narrative panel
- Named customer quote
- Compact mobile call and schedule bar

## Motion

Only subtle opacity and transform reveals, disabled for reduced motion. No autoplay or carousels.
